# 엔비디아 (NVDA) 최근 1개월 주식 대시보드

주식 입문자도 쉽게 이해할 수 있도록 정리한 **엔비디아(NVIDIA, NASDAQ: NVDA)** 최근 1개월(2026.10.21 ~ 2026.11.20) 주식 대시보드입니다.

> ⚠️ **안내:** 본 자료는 **AI 초안**이며, **저장된 공개 자료 기준(2026년 11월 20일 종가 마감)**으로 작성되었습니다. **실시간 시세가 아니며**, 투자 권유 목적이 아닌 학습·참고용 자료입니다.

## 주요 구성
- **한눈에 보는 핵심 요약:** 최근 1개월 주요 지표(종가·변동률·최고/최저 종가)와 `[사실]` · `[AI 해석]` 나란히 비교
- **독립 실행형 종가 차트:** 외부 라이브러리(CDN) 없이 오프라인·인쇄/PDF에서도 선명한 벡터 SVG 차트
- **초보자용 회사 소개:** 핵심 사업과 제품군을 쉬운 표현으로 정리
- **관련 뉴스 7건:** 실제 본문을 확인한 기사만 요약하고 원문 출처 링크 연결
- **인쇄 / PDF 저장 지원:** 상단 버튼 및 인쇄 전용 레이아웃(`@media print`) 포함

## 포함 파일
- `index.html` — GitHub Pages 메인 대시보드
- `stock-report.html` — 인터넷 없이 단독으로 열어볼 수 있는 동일 리포트 파일

## 데이터 출처 및 기준일
- **시세 기준일:** 2026년 10월 21일 ~ 2026년 11월 20일 (미국 나스닥 마감 종가, USD)
- **출처:** Investing.com 공개 시세, NVIDIA 공식 IR 보도자료, The Guardian, Fortune, The Motley Fool, Morningstar (PR Newswire)
